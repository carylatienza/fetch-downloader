## Requirements
### Requirement: Root README document exists and is informative
The repository SHALL contain a root `README.md` file presenting the project branding, features, supported platforms, installation instructions, environment setup, and architecture summary.

#### Scenario: Developer visits the repository
- **WHEN** a developer views `README.md` at the project root
- **THEN** it displays project overview, badges, supported platforms (YouTube, Facebook, Instagram, X), installation instructions (`npm install`, `npm run dev`), API endpoints, and project structure

#### Scenario: Visual formatting elements
- **WHEN** reading `README.md`
- **THEN** it includes formatted code blocks, status badges, feature tables, tech stack icons, and clear section dividers
