## MODIFIED Requirements

### Requirement: Media preview card
The system SHALL display interactive `<` and `>` carousel navigation controls and a `Photo X of Y` indicator badge inside the thumbnail container for multi-photo items.

#### Scenario: Image container carousel navigation
- **WHEN** media item contains multiple images
- **THEN** preview card displays `<` and `>` arrow buttons over the thumbnail image, displays `Photo X of Y` counter badge, and allows clicking arrows to switch the active photo preview
