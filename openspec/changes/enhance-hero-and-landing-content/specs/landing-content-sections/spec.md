## ADDED Requirements

### Requirement: Platform Capability Matrix Component
The system SHALL present a structured matrix section detailing supported formats, video resolutions, and gallery archive options for YouTube, Facebook, Instagram, and X.

#### Scenario: User views platform matrix
- **WHEN** the user scrolls to the Platform Matrix section
- **THEN** cards displaying supported capabilities per platform (e.g. 4K MP4, Reels, Carousel ZIP) are rendered

### Requirement: Fetch vs Traditional Downloaders Comparison Table
The system SHALL display a visual comparison table highlighting key advantages of Fetch over traditional media downloader sites.

#### Scenario: User views comparison table
- **WHEN** the user scrolls to the Comparison section
- **THEN** a table comparing Ads, Multi-photo support, Preview capabilities, and Resolution between Fetch and typical sites is displayed

### Requirement: Interactive FAQ Accordion Component
The system SHALL provide an interactive FAQ section with expandable disclosure panels addressing privacy, legal, file limits, and ZIP downloads.

#### Scenario: User expands an FAQ item
- **WHEN** the user clicks on an FAQ question header
- **THEN** the corresponding answer panel smoothly expands to reveal the full response
