## ADDED Requirements

### Requirement: Platform badges shall feature real, active public Rick Astley media links
All sample buttons in `PlatformBadges.js` SHALL use verified, active public URLs across YouTube, Instagram, Facebook, and X.

#### Scenario: User clicks Instagram, Facebook, or X sample button
- **WHEN** user clicks any supported platform badge
- **THEN** the URL input is populated with an active public media URL
- **AND** extraction completes successfully
