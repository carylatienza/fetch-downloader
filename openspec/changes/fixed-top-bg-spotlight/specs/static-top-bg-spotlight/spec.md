## ADDED Requirements

### Requirement: Fixed Top Background Ambient Spotlight
The system SHALL render a static, fixed radial spotlight aura at the top center of the viewport backdrop behind the hero section.

#### Scenario: User views any page
- **WHEN** the user loads or scrolls through any page
- **THEN** a soft ambient violet radial glow is positioned statically at the middle-top of the background canvas with no cursor tracking
