## ADDED Requirements

### Requirement: Platform sample badges shall use active, valid public Rick Astley media URLs
The `PLATFORMS` sample list in `PlatformBadges.js` SHALL contain live, verified public Rick Astley video and photo URLs across YouTube, Instagram, Facebook, and X.

#### Scenario: User clicks sample badge
- **WHEN** user clicks YouTube, Instagram, Facebook, or X sample badge
- **THEN** the URL input is populated with a valid, extractable Rick Astley media link
