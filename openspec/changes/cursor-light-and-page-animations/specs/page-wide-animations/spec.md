## ADDED Requirements

### Requirement: Page-Wide Animations & Motion Polish
The system SHALL execute scroll-reveal animations across all site pages (`/`, `/about`, `/how-it-works`, `/faq`, `/privacy`, `/terms`) and deliver smooth hover micro-animations.

#### Scenario: User visits any page and scrolls down
- **WHEN** the user navigates to `/about`, `/how-it-works`, `/faq`, `/privacy`, or `/terms` and scrolls
- **THEN** page elements reveal smoothly with staggered fade-and-translate animations as they enter the viewport
