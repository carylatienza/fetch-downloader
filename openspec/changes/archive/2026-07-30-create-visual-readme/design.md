## Context

Fetch is a high-performance, dark-aesthetic all-in-one media downloader web app built with Next.js 15, React 19, Lucide React, and `yt-dlp` / `ffmpeg`. Creating a top-tier `README.md` gives the project a strong open-source presence.

## Goals / Non-Goals

**Goals:**
- Design a GitHub-ready `README.md` featuring project badges, hero tagline, feature highlights, platform matrix, tech stack, prerequisites, quick start guide, API docs summary, and folder tree.
- Incorporate clean Markdown styling with tables, badges, emoji icons, and code blocks.

**Non-Goals:**
- Modify application source code or build configuration.

## Decisions

- **Decision 1: Section Structure**:
  1. Header & Hero Banner / Badges
  2. Features Highlight
  3. Supported Platforms
  4. Tech Stack Overview
  5. Getting Started (Installation & Environment Variables)
  6. API Reference (`/api/extract`, `/api/download`, `/api/proxy-image`)
  7. Project Structure
  8. License & Acknowledgments

## Risks / Trade-offs

- None. Documentation-only change.
