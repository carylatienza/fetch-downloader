## ADDED Requirements

### Requirement: Zero Card Disappearance on Hover
The system SHALL provide interactive card hover spotlights without React class mutations or scroll-reveal opacity resets.

#### Scenario: User hovers over platform cards or bento boxes
- **WHEN** the user hovers and moves the cursor over any platform matrix card or bento box
- **THEN** all card headers, logos, titles, descriptions, and feature lists remain 100% visible at all times
